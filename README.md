# جودة الهواء في سوريا — لوحة الرصد البيئي والطقس والانبعاثات الصناعية

تطبيق ويب تفاعلي باللغة العربية (`RTL`) ومتجاوب مع الهواتف والحواسيب لعرض وتحليل البيانات البيئية والطقس وجودة الهواء والانبعاثات الكربونية الصناعية في المحافظات السورية الـ 14 اعتماداً على واجهات برمجية حية ومفتوحة بالكامل دون بيانات ثابتة أو وهمية.

---

## المزايا الرئيسية

- **خريطة سوريا التفاعلية ثلاثية الأبعاد**: عرض المحافظات الـ 14 مع تلوين ديناميكي حسب مؤشر جودة الهواء الأمريكي الحي (`US AQI`)، وأعمدة إضاءة، ومسارات ربط جغرافية، وتصفية حسب مستوى التنبيه، ونافذة فحص تفصيلية لكل محافظة.
- **مؤشرات جودة الهواء والملوثات الحية**: حلقات قياس مبنية على عتبات `US EPA / WHO` لكل من `US AQI` والأوزون `O₃` و`PM10`، وأشرطة نسبية للملوثات، وسلسلة زمنية لآخر 24 ساعة، وترتيب جميع المحافظات الـ 14، ومخطط رادار ديناميكي لأعلى 6 محافظات في المؤشر.
- **توقعات الطقس اليومية (5 أيام)**: درجات الحرارة العظمى والصغرى، واحتمال الهطول، وسرعة الرياح القصوى، وحالة الطقس وفق رموز المنظمة العالمية للأرصاد الجوية (`WMO`) على مستوى سوريا أو لكل محافظة محددة.
- **مقارنة محافظتين جنباً إلى جنب**: اختيار أي محافظتين لمقارنة مؤشر جودة الهواء، والملوثات، وحالة الطقس الحالية، وتوقعات الأيام الخمسة، والاتجاه الساعي.
- **المؤشرات البيئية التاريخية (البنك الدولي)**: عرض أحدث 5 سنوات مكتملة ومشتركة لانبعاثات `CO₂` الكلية، ومتوسط التعرض السنوي لـ `PM2.5`، ونصيب الفرد من `CO₂`.
- **رسم بياني تفاعلي بمكتبة D3.js للكربون والأنشطة الصناعية**:
  - مخطط فقاعي يوضح العلاقة بين عدد الأنشطة والمنشآت الصناعية المسجلة وانبعاثات `CO₂e` عبر السنوات مع مسار تتبّع زمني لكل محافظة وخط اتجاه ومقياس نسبي/خطي وتشغيل زمني.
  - مخطط مساحي مكدّس لتطور القطاعات الصناعية (النفط والغاز، توليد الكهرباء، الإسمنت والصناعات الثقيلة، الوقود الصناعي والتجاري).
  - قائمة تفصيلية للمنشآت المسجلة متزامنة مع الخريطة، مع فصل مجمّعات النفط والغاز الوطنية عن المحافظات الفردية.

### المعايير والتصنيفات المرجعية المعتمدة

- **تصنيف مؤشر جودة الهواء (`US EPA AQI`)**: جيد (`0–50`)، متوسط (`51–100`)، مرتفع (`101+`) — [AirNow / US EPA AQI Basics](https://www.airnow.gov/aqi/aqi-basics/).
- **إرشادات منظمة الصحة العالمية لجودة الهواء (`WHO AQG`)**: القيم المرجعية لتركيز الجسيمات العالقة `PM2.5` و`PM10` والأوزون `O₃` — [WHO Global Air Quality Guidelines](https://www.who.int/publications/i/item/9789240034228).
- **الحدود الإدارية ورموز المحافظات (`GADM ADM1`)**: ربط سجلات المحافظات السورية الـ 14 وفق الرموز الرسمية `SYR.1` إلى `SYR.14` — [GADM Syria Administrative Maps](https://gadm.org/maps/SYR.html).
- **رموز حالات الطقس القياسية (`WMO WW 4677`)**: تفسير حالات الصحو، الغيوم، الضباب، الأمطار، الثلوج، والعواصف الرعدية.

## منهجية معالجة البيانات وضمان الدقة

1. **عدم توليد أو تعويض قيم وهمية**: تُستبعَد أي قراءة مفقودة (`null` أو غير رقمية) بدلاً من تحويلها إلى أصفار افتراضية، ويُحسَب المتوسط الوطني الساعي فقط من المحافظات التي تمتلك قراءة فعلية للطابع الزمني ذاته.
2. **تنظيف سجلات الانبعاثات الصفرية**: تستبعد وحدة معالجة `Climate TRACE` أي أصل أو سجل بقيمة انبعاث `<= 0` طن حتى يعكس عدد الأنشطة المسجلة المنشآت المقاسة فعلياً فقط.
3. **فصل المجمّعات الوطنية عن المحافظات**: تُفصَل سجلات مجمّع الأحواض الوطني للنفط والغاز (`Syria_OtherBasins_OtherResources`) عن المحافظات الفردية وتُعرَض ضمن الإجمالي الوطني (`إجمالي سوريا`) لمنع نسبتها خطأً إلى محافظة واحدة.
4. **مقاييس رسوم غير مشوّهة**: تُرسَم جميع الأشرطة وحلقات القياس والمخططات بنسب حقيقية مستندة إلى المعايير الرسمية أو الحدود الفعلية للبيانات دون تضخيم اصطناعي.

## التقنيات المستخدمة

- **React 19** + **TypeScript** + **Vite 8**
- **Tailwind CSS v4**
- **D3.js v7** (الرسوم البيانية التفاعلية للانبعاثات والأنشطة الصناعية)
- **Lucide React** (الأيقونات)

## التشغيل المحلي

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير على المنفذ 3000
npm run dev

# فحص الأنواع (TypeScript)
npm run lint

# بناء نسخة الإنتاج
npm run build
```

> لا يتطلب التطبيق أي مفاتيح API خاصة؛ جميع واجهات البيانات المستخدمة مفتوحة ومباشرة (`Open-Meteo` و`World Bank Open Data` و`Climate TRACE v6`).
